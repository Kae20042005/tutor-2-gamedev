# Latihan: manipulasi node dan scene

1) Fungsi node bertipe Sprite2D adalah untuk menampilkan gambar 2D di layar. Lalu, untuk isi dari gambarnya dapat dipilih dari direktori yang ada.
2) Objek dengan tipe RigidBody2D dapat dipengaruhi oleh physics game seperti mass, gravity, dan velocity. Sedangkan objek dengan tipe StaticBody2D tidak terpengaruh oleh physics game.
3) Tidak ada perubahan.
4) Ketika atribut Disabled milik node CollisionShape2D, objek BlueShip tidak lagi bersentuhan dengan stone platform sehingga objek langsung jatuh.
5) Ketika atribut position, rotation, dan scale milik node BlueShip diubah, maka posisi Object Blueship akan berupah pada layar
6) StonePlatform dan StonePlatform2 memiliki posisi berdasarkan PlatformBlue, sehingga nilai position yang ada di inspector dan visual berbeda.
